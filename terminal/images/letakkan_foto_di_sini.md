# 📁 Folder `images/`

Letakkan foto profilmu di sini.

## Cara pakai:

1. Salin foto kamu ke folder ini (contoh: `foto.jpg`)
2. Update `data.json` bagian `header.foto`:
   ```json
   "foto": "images/foto.jpg"
   ```

## Format yang didukung:

- `.jpg` / `.jpeg`
- `.png`
- `.webp`
- `.gif`

> Jika foto tidak ditemukan, website akan otomatis menampilkan avatar inisial nama.
