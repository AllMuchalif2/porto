# 🎨 Multi-Style Portfolio Collection

Proyek ini adalah koleksi template portofolio pribadi yang fleksibel, di mana semua data dikelola melalui satu file `data.json`.

## 🚀 Cara Menggunakan

1. **Clone gaya tertentu:**

   ```bash
   git clone -b style/minimalist https://github.com/AllMuchalif2/porto.git
   ```

2. **Edit Data:**
   Buka file `data.json` dan ganti isinya dengan informasi pribadimu.

3. **Ganti Foto:**
   Masukkan foto kamu ke dalam folder `images/` dan update jalurnya di `data.json`.

---

_Dibuat dengan sistem Vanilla JS & CSS Grid._
